# Kopitiam Mini Sprite Pack

Open **PREVIEW.html** to inspect the artwork, animations and simulated states.

Read **Kopitiam_Agent_IDE_Sprite_Production_Plan.md** for which sprite to use, timing, layer order, anchors, rendering sizes and backend state mapping.

Use **manifest.json** and **state-map.json** for integration. Runtime PNGs are small by design; use integer nearest-neighbor scaling. The large generated sheets in `sources/` are editing references.

This is the core prototype asset pack: 433 individual PNG sprites, including 252 character animation/hold frames. See **VALIDATION.md** for checks and limitations.
