# Kopitiam Subagent Customers

Open **PREVIEW.html** for the offline animation demo. Read **Kopitiam_Subagent_Customers.md** for visual behaviour, agent-state mapping, placement and integration.

Use the 32 × 40 PNGs under **customers/** or the five atlases under **atlases/**. The enlarged **sources/** are reference artwork, not runtime textures.

The pack contains five back-facing customer variants, 80 exported frames, one separate stool, 20 shared badges, metadata and 30 GIF previews. No live agent backend is included.
